### 🖤 Sobre Mim

Desenvolvedor **Frontend** focado em criar interfaces funcionais, limpas e bem estruturadas. Tenho apreço pelos detalhes visuais, pela organização de código e por transformar conceitos em código legível e eficiente.

* 💻 Atuando na criação de aplicações web com foco em performance e experiência de uso.
* 🛠️ Trabalhando com **HTML, CSS, JavaScript** no ecossistema web e **Python** no apoio a scripts e lógica.
* 🎯 Sempre buscando aperfeiçoar o fluxo de versionamento com **Git e GitHub**.
